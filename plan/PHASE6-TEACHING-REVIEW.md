## Implemented

- Teaching entry points in Computer and Memory & skills; recoverable recording list, explicit capture controls, private-input acknowledgement, evidence/image selection, editable Markdown, task tests, owner result verification, publication and retention controls.
- Hermbot-owned accepted-RFB observer with fragmented/coalesced messages, normal/QEMU keys and clipboard omission. The native Hermes input gate remains authoritative and unchanged. Geometry, image dimensions, segment/generation/sequence and capture time accompany retained observations.
- Bounded volatile collector; paused/disconnected/lease-changed input and late private-generation frames are excluded. Initial/transition/final keyframes are observations, never proof of application success. Pane-close now waits for a dedicated ordinary-pause acknowledgement; native WebSocket disconnect independently pauses capture. Human control persists until explicit handback.
- PostgreSQL state/manifests, immutable encrypted evidence/draft revisions and encrypted private S3 chunks. Recordings are not Library artifacts. Staged objects are verified before manifest commit; retries acknowledge only committed prefixes. Deletion/expiry stops active candidate tests through the existing cancellation path, fences processing, clears the matching volatile collector and retries private-object deletion. Unreferenced staged objects are reconciled separately.
- Durable, bounded model generation with the bot's configured provider; no execution tools. Only owner-saved reviewed text and selected images are processed. Provider identity/revision, source digest and job token fence late output. Cancellation, input edits and deletion invalidate outstanding results. A bounded repair handles malformed drafts; a structured `max_tokens` rejection is retried with `max_completion_tokens`.
- An authenticated candidate is visible only to its test task. Preparation and supported tool-execution middleware consult that immutable candidate without writing or globally enabling a native skill. Tests use ordinary tasks, work control, permissions, management grants, Stop and action reviews.
- Publication requires the exact current evidence/draft/configuration, a completed candidate consultation, and an owner's recorded observations that the checks passed. Native CAS, readback, immutable knowledge history and runtime refresh reuse the existing knowledge path. Published rollback remains an explicit new version through Memory & skills.

## November 2 feedback-loop implementation and review

- Migration 019 adds encrypted source/result snapshots for deduplicated refinements, current learning reports and test-specific automatic-refinement markers. Existing tests are not automatically opted in by migration.
- Settled tests feed source-linked revisions automatically. Sources include exact-test owner answers (both form and chat routing), associated owner corrections/steering, outcome states and reports. Unrelated chat and non-owner answers are excluded. Prior feedback survives failed refinement/retry; owner instructions are not silently truncated.
- Teaching questions belong to current session/draft/evidence. Reusable versus execution-specific scope is explicit; answering the last question queues a successor draft. Confirmed answers and one-off instructions are labeled separately from model reports. Model interpretation of semantic scope still needs owner inspection and functional testing; the app does not claim to prove that interpretation deterministically.
- Model output includes a concise summary, source-linked changes/questions and suggested fresh inputs/checks. The colour-band canary was removed: colour naming cannot establish model capability. Only selected actual images are sent. Authentication, rate, HTTP, transport, timeout and invalid-output failures have distinct safe messages without raw provider bodies.
- Current hashes/revisions/job tokens fence late model results. Active tests/native attempts delay refinement. Old questions cannot modify a manually edited draft. Pending/failed processing and unanswered questions prevent publication; automatic refinement never starts another test or applies a native skill.
- UI leads with the next question or learning result, preserves local edits across polling, and keeps Markdown editing under an advanced disclosure. Execution finished and owner-verified checks are distinct labels. Computer and Memory & skills protect unsaved teaching edits on dismissal.
- Computer close/Esc/backdrop use a confirmed ordinary-pause endpoint. Failed acknowledgement leaves the pane open. A status strip outside dialogs shows saved observations/bytes, recording/paused/saving state and a reopen action; the relevant session is restored. Remote-focused Escape stays with the remote surface. Abrupt page shutdown still relies on keepalive/disconnect fallback; the app does not claim that sending a request proves durable saving.
